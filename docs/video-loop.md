我要开发一个obsidian plugin，我的想法是，需要用户给一个视频和一个字幕文件，用户能够反复听一句话的发音，磨一磨用户的耳朵，用场景的方式来眼熟英语。

本软件需要展现给用户的是

1. 视频播放页面，单独一个标签页（我希望画面和声音的场景能够帮助用户）
2. 字幕显示页面，单独一个标签页（用户看着字幕自己shadow跟读；但是除了字幕这个页面还有AB播放控制）
3. 显示的当前字幕 和 播放的当前视频 进度要双向绑定；点击句子跳转
4. 需要实现AB播放，字幕页面点击A，播放视频，字幕页面点击B，则记录AB段，然后AB段循环播放。点击AB则结束循环播放

数据管理方面的设计还需要讨论？

1. 视频因为文件太大了，我不希望放在obsidian vault，通过绝对路径找到对应的视频
2. 字幕文件我认为可以在vault中，会用专门的ass等
3. 我觉得是需要有一个列表页面展示着所有的item，用一个md来关联一项的视频link和字幕link（md的metadata）
