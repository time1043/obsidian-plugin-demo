# Video Loop Demo

This file demonstrates how to use the Video Loop plugin.

## How to use

1. Set `video` in frontmatter to the absolute path of your video file
2. Set `subtitle` in frontmatter to the vault-relative path of your .ass subtitle file
3. Run the command "Open Video Loop from current file" or click the play ribbon icon
4. Two tabs will open: video player and subtitle viewer
5. Click any subtitle line to jump to that moment in the video
6. Use A/B buttons to set loop points for repeated listening
